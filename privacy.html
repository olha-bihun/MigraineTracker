Політика конфіденційності

Дата редакції: 17 жовтня 2026 року.

Дані щоденника

MigraineTracker зберігає на вашому пристрої дати записів, тип мігрені, вибрані тригери, коментарі, власні тригери та налаштування. Застосунок не передає ці записи розробнику й не має власного сервера або синхронізації між пристроями.

Аналітика та реклама

У застосунку немає акаунтів, рекламних SDK, вбудованої аналітики або відстеження користувачів. Він не підключається до HealthKit.

Керування даними

Запис дня можна видалити через меню біля дати. Видалення тригера зі списку приховує його, але зберігає зв’язки з попередніми записами. Видалення застосунку через команду iOS «Видалити програму» прибирає його локальні дані; «Звантажити програму» зберігає їх.

Резервні копії

Системні резервні копії iPhone можуть містити дані застосунку залежно від налаштувань Apple. Розробник не має доступу до цих копій. Керування ними здійснюється засобами Apple.

Звернення в підтримку

Якщо ви добровільно звертаєтеся електронною поштою, власник отримує адресу та вміст повідомлення для відповіді. Не додавайте чутливі медичні дані або скриншоти особистих записів без потреби. Повідомлення використовуються для розгляду звернення та подальшого листування щодо нього. Щоб попросити видалити ваше листування, напишіть на адресу підтримки.

Вебсайт

Сторінки підтримки розміщені на GitHub Pages. GitHub може обробляти IP-адресу та технічні дані запитів для безпеки хостингу згідно зі своєю політикою конфіденційності. На цих сторінках немає доданої нами аналітики чи реклами. Дані щоденника на сайт не передаються.
